# Local library changelog

## Profile 1.3.0 — 10 October 2026

- Host-owned package/hash, public contract and migration-ledger validation at
  packaging, installation and startup. Artifact/version disagreement is refused.
- Four logical CRM module contracts, typed deterministic assembly planner, local
  dry-run/assembly command and independent minimal/full consumer evidence.
- Stopped-host module lifecycle closes disabled UI/tools/routes/writes and retains
  data, audit and original receipts. Unresolved native effects block disable.
- Scoped offline presence contract shared by installed chat and a standalone Python
  synthetic transcript consumer. Guest/owner identity, page revision, request replay,
  bounded tools, expiry and timeout behavior are server-controlled.
- Exact external runtime version pins and a reproducible 15-control security matrix,
  current advisory scans and dependency/license/notice inventory.
- Isolated two-tenant baseline with 200 additional contacts per tenant, tasks and
  opportunities, mixed authenticated reads at concurrency 1/5/20, and a separate
  20-request duplicate mutation/recovery race.
- Prior profile 1.0.0 cold-source upgrade retains records, grants, audit and UUID
  receipts. Fresh restore invalidates identity and old consent, sets native/provider
  holds and requires explicit recovery. Minimal/full Chromium flows are verified.
- Cold-install, composition, upgrade/recovery and operation guide with sanitized
  evidence. No pricebook, business data or ownership policy changed.

This release adds no database migration over profile 1.0.0. The supported package
closure is 25 internal artifacts with 18 external runtime pins. See the
[catalogue](../config/library-release.v1.json) and [handoff](LOCAL_LIBRARY_HANDOFF.md).
Realtime provider/template integration, production operation and broader business
modules remain separate milestones.
