# Archava — audit dan perapihan docs, 29 Oktober 2026

Folder `docs/` sudah dirapikan berdasarkan fungsi dan status dokumen. Audit mencakup **seluruh 492 file yang ada saat pekerjaan dimulai**, termasuk 101 log yang tidak muncul pada pencarian file biasa karena aturan ignore. Tabel di bagian akhir memberi keputusan untuk setiap file awal. Tidak ada file awal yang dihapus.

Panduan aktif sudah dibedakan dari kontrak lama, rencana, riset, studi visual dan bukti audit. Delapan dokumen arsitektur/integrasi yang sebelumnya mencampur implementasi dengan aspirasi ditulis ulang berdasarkan source; versi aslinya disimpan identik. Ini audit dokumentasi dan kepemilikan folder, bukan pentest baru atau sertifikasi siap launching.

Pernyataan aktif tentang API dan subsistem yang bermasalah ditelusuri ke source Rust/JavaScript. Pernyataan historis tidak seluruhnya dibuktikan ulang.

## Batas implementasi yang tetap perlu ditangani dalam pekerjaan kode

Dokumentasi sekarang menyebut batas berikut secara eksplisit. Audit ini tidak mengubah implementasinya:

- Cockpit memakai state in-memory; handler penyelesaian step mengabaikan hasil persistence SQL setelah mengubah state memory.
- Orbz memakai estimasi byte/4 untuk token dan reflection berbasis pola; cabang entity scope belum membuktikan keanggotaan entity tertentu.
- Pemanggilan tool eksternal MCP saat ini menghasilkan respons dispatch simulasi; RPA menghasilkan resep aksi tanpa membuktikan browser executor.
- Evaluasi finansial memakai validator jurnal aktual, sedangkan kasus lain memakai target/pola lokal; hasil suite bukan skor universal model yang terdeploy.
- Keberadaan komponen domain, provider, webhook atau hardware tidak membuktikan seluruh alur host/produk sudah terpasang.
- Browser client sudah membedakan callback pembayaran simulasi. Callback browser tetap memerlukan receipt/provider authority untuk efek bisnis.
- Operations masih merupakan demo, dan verifier rilis operator masih perlu diselaraskan dengan kontrak distribusi saat ini.

Rujukan source dan batasnya tersedia di [arsitektur subsistem](../architecture/README.md) serta [panduan integrasi](../integration/README.md). [Source bindings](evidence/docs-audit-2026-10-29/source-bindings.json) merekam hash file yang dirujuk saat review.
