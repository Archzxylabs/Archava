Frozen bodies retain original bytes, including paths and statuses such as “active”. Relative links in them can reflect their pre-consolidation location. Use the [relocation manifest](relocations-2026-10-29.json) to find their current target: `originalPath` is the path before this consolidation, and `currentPath` is its replacement. No archived claim becomes current acceptance because it remains here. Maintained collection indexes link directly to current locations.
