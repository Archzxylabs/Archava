# Public embedded catalogues

These two JSON files are generated byte-for-byte snapshots of the authoritative
catalogues under the repository's `config/`. Rust includes these internal paths
so a normal Cargo package can compile without the original checkout.

After editing either canonical catalogue, run
`node tools/rust/domain-assets.mjs --write` from the repository root. Do not edit
the snapshots separately. Structure verification and build provenance reject
missing or stale snapshots. The helper copies only the two declared public JSON
files; private configuration and credentials do not belong in this directory.
